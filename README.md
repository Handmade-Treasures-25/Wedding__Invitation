# Luxury Wedding Invitation — GitHub Ready

A premium single-page interactive wedding invitation template built with:
- HTML
- CSS
- Vanilla JavaScript
- No framework
- No RSVP
- No video

## Included interactions
1. Animated opening / unveiling button
2. Scratch card with a 60% reveal trigger
3. Shimmer / bloom / burst particles after reveal
4. Scroll reveal animations
5. Live wedding countdown
6. Track Location button opening Google Maps
7. Floating luxury sparkles

## Files
- index.html
- style.css
- script.js

## Quick setup
Upload all three files to the same GitHub repository. Open `index.html` or enable GitHub Pages.

## Easy edits
Search in `index.html` for:
- Emily & Alexander
- 18 · OCTOBER · 2026
- St. Claire Chapel
- Villa Bellavista
- Lake Como, Italy

Search in `script.js` for:
- `const weddingDate`

Replace those values with your customer's details.

## Logo / monogram
The `E & A` monogram is CSS text, so there is no external logo file required. Replace the letters in `.monogram` and `.closing-mark` with the couple's initials.

## Important
The location is a template/demo location. Replace it before publishing a real invitation.
